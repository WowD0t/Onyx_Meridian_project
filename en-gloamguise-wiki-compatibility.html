Compatibility

Versions, platforms, servers and other packs — what works out of the box.

ItemStatusDetails
Minecraft Bedrock1.26.40 – currentNo beta APIs, no experiments
Script API@minecraft/server 2.9.0Bundled dependency, no separate install
MultiplayerSupportedHost or server installs the pack; clients get blocks and subtitles
RealmsSupportedUpload both packs to the Realm slot
Other add-onsCompatibleOwn gg: namespace, no vanilla block is replaced
Texture packsMostlyPacks that retexture stone or wood change the copied look too — expected
Worlds with older versionsUpgradeableRemove v2.0.x packs first, then import the current file
Your textures, your disguise
The camouflage copies whatever your resource packs show for the neighbouring block, so the disguise always matches your own visual style.

Platform list

Windows, Android, iOS, Xbox, PlayStation, Switch, Realms and dedicated servers. Languages: English and Russian — all tooltips, subtitles and messages.

Java Edition
This is a Bedrock add-on. It does not run on Java Edition, and porting is not permitted by the licence.
