# Onyx Meridian Interactive Studio

**English**

Onyx Meridian Interactive Studio is an independent studio building gameplay systems for Minecraft Bedrock. This repository is the studio's main home: the public website, shared legal documents, official-source rules, notification centre, support form and studio-level documentation.

The studio publishes add-ons as separate projects. Each add-on has its own page on the website, its own GitHub repository and its own GitHub Wiki. The studio repository connects those projects; it does not replace them.

## What lives here

- The static studio website for GitHub Pages.
- The studio hub: add-on catalogue, official sources, announcements, notifications, licensing and support.
- The shared **OM Studio EULA v3.1** in English, Russian and combined form.
- A bilingual support and permission-request form delivered through Web3Forms.
- Studio-wide documentation about official channels, repositories, permissions and releases.

## Site features

- The top navigation is rebuilt around real destinations: Studio, Add-ons, Wiki hub, Roadmap, Licence and Support. The three-line button in the top corner opens a site menu; settings open as a separate drawer.
- Settings include theme, accent colour, text size, density, hero layout, article width, link underlining, animations, background effects, performance mode and language. Text size scales the whole typographic scale.
- Performance mode can be Auto, Full or Lite. Lite keeps the layout and colours but disables heavy effects for weak devices.
- Keyboard shortcuts are layout-independent: Ctrl K or / search, M menu, S settings, T theme, L language, N notifications, G then H/A/W/R/L/S/V navigation, ? help.
- The Gloamguise page shows a site-download counter and a live CurseForge counter. A site download is counted once per browser/device using local storage, a cookie and IndexedDB; it is an approximate site metric, not a unique-person guarantee. A Cloudflare Worker reference implementation is included in `tools/counter-worker.js` for stronger server-side deduplication.
- Wiki pages include a reading progress bar, version chip, copy-link and print actions, heading anchors, table-of-contents highlighting, copy buttons and related-page links.
- Extra pages: Add-ons catalogue with filters, Wiki hub, Roadmap with version comparison, full-site Search, and a local SHA-256 Verify page.
- The site ships an RSS/JSON update feed, optional browser update alerts, a web app manifest and a service worker for offline caching.

## Возможности сайта

- Верхняя навигация перестроена вокруг реальных разделов: Студия, Аддоны, Вики-хаб, Планы, Лицензия и Поддержка. Кнопка с тремя полосками в верхнем углу открывает меню сайта; настройки открываются отдельной панелью.
- Настройки включают тему, акцентный цвет, размер текста, плотность, главный блок, ширину статьи, подчёркивание ссылок, анимации, фоновые эффекты, режим производительности и язык. Размер текста масштабирует всю типографическую шкалу.
- Режим производительности: Авто, Полный или Облегчённый. Облегчённый сохраняет макет и цвета, но отключает тяжёлые эффекты для слабых устройств.
- Горячие клавиши не зависят от раскладки: Ctrl K или / поиск, M меню, S настройки, T тема, L язык, N уведомления, G затем H/A/W/R/L/S/V навигация, ? справка.
- Страница Gloamguise показывает счётчик скачиваний с сайта и живой счётчик CurseForge. Скачивание с сайта засчитывается один раз на браузер/устройство через localStorage, cookie и IndexedDB; это приблизительная метрика сайта, а не гарантия уникальности человека. Для более строгой серверной дедупликации включён эталонный Cloudflare Worker в `tools/counter-worker.js`.
- Страницы вики содержат прогресс чтения, метку версии, копирование ссылки и печать, якоря заголовков, подсветку оглавления, кнопки копирования и связанные страницы.
- Дополнительные страницы: каталог аддонов с фильтрами, вики-хаб, планы со сравнением версий, поиск по всему сайту и локальная проверка SHA-256.
- Сайт содержит RSS/JSON ленту обновлений, необязательные уведомления браузера, манифест веб-приложения и service worker для офлайн-кеша.
