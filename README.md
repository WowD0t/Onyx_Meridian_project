# Onyx Meridian — сайт студии + вики Gloamguise (ПЛОСКАЯ сборка)

Эта папка собрана **без подпапок**: все HTML, CSS, JS и картинки лежат одним
уровнем с уникальными именами (`en-index.html`, `ru-gloamguise-wiki-engine.html`,
`assets-css-style.css`, `assets-img-…png`). Все внутренние ссылки уже переписаны
под эти имена. Поэтому сайт можно загрузить на GitHub **обычными файлами**,
без создания папок и без GitHub Actions.

## Как опубликовать (только файлы, через браузер)

1. Создайте репозиторий на GitHub (публичный), ветка `main`.
2. Откройте репозиторий → **Add file → Upload files**.
3. Перетащите **ВСЕ файлы из этой папки** (выделите их в проводнике, не саму
   папку) в окно загрузки. GitHub примет их одним коммитом.
   - Скрытый файл `.nojekyll` тоже нужен: он отключает Jekyll. Если проводник
     его не показывает, включите «скрытые файлы» или создайте его вручную:
     **Add file → Create new file**, имя `.nojekyll**, содержимое пустое.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
   Branch: `main`, папка: `/ (root)` → **Save**.
5. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.
   Стартовая страница сама выберет язык (RU/EN) и переадресует на хаб.

Никакие workflows не требуются: Pages отдаёт файлы прямо из корня ветки.

## Что внутри

- `index.html` — стартовый сплэш с эмблемой и выбором языка (авто-редирект).
- `404.html` — двуязычная страница «не найдено» (GitHub Pages использует её).
- `en-*.html` / `ru-*.html` — хаб → страница аддона → 17 страниц вики на язык.
- `assets-css-style.css` — дизайн-система: тёмная + светлая темы, анимации,
  плавные переходы между страницами.
- `assets-js-app.js` — переходы, темы, поиск (Ctrl+K / `/`), лайтбокс, копирование
  ID, scrollspy, счётчики, мобильное меню.
- `assets-js-search-index.js` — полнотекстовый индекс (RU+EN).
- `assets-img-*` — скриншоты, GIF, иконка CurseForge, аватар и **эмблема студии**
  (`emblem.png`, `emblem-256.png`, `emblem-64.png`) с прозрачным фоном.

## Возможности

- Тёмная и светлая темы (переключатель в шапке, запоминается).
- Плавные кросс-страничные переходы без «моргания», stagger-анимации, hover-эффекты.
- RU/EN переключатель с сохранением текущей страницы.
- Поиск по всей вики, лайтбокс картинок, копирование ID блоков в один клик.
- Адаптив до 390px и ниже; уважает `prefers-reduced-motion`.

## Вики GitHub (отдельно)
