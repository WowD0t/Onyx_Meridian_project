FAQ

The questions people actually ask — answered straight.

2 min read1 sections
Do I need experimental toggles?
No. The pack runs on stable 1.26.40+ with the bundled Script API 2.9.0.
Can I use it on a public server?
Yes. The server needs the pack; players do not have to install anything themselves.
Will it break my existing world?
No blocks are replaced and no vanilla files are overwritten. Removing the pack leaves vanilla blocks behind, so back up before you uninstall if you built with decoys.
How do I link a torch again after breaking it?
Break and replace: the link is stored with the torch position. You can also Shift + tap a linked torch while holding a fresh torch to copy its link.
Why does a door not open by hand?
You are using the _rs variant, which is deliberately hand-locked. Power it with redstone or link a remote torch.
Can two people share one door?
Yes. Every player can link their own torch to the same door; all linked torches stay in sync.
Does the pack phone home?
No telemetry, no analytics, no network requests. All state lives in your world’s dynamic properties.
Is it compatible with Java Edition?
No. This is a Bedrock add-on; porting is not permitted by the licence either.
Can I include it in my modpack or server pack?
Not without written permission — see the licence. Write to yarik.internet@atomicmail.io.
Do you take commissions?
Yes. Write to yarik.internet@atomicmail.io with the scope and the deadline.
