# FAQ

The questions people actually ask — answered straight.

**Do I need experimental toggles?**

No. The pack runs on stable 1.26.40+ with the bundled Script API 2.9.0.

**Can I use it on a public server?**

Yes. The server needs the pack; players do not have to install anything themselves.

**Will it break my existing world?**

No blocks are replaced and no vanilla files are overwritten. Removing the pack leaves vanilla blocks behind, so back up before you uninstall if you built with decoys.

**How do I link a torch again after breaking it?**

Break and replace: the link is stored with the torch position. You can also **Shift + tap** a linked torch while holding a fresh torch to copy its link.

**Why does a door not open by hand?**

You are using the `_rs` variant, which is deliberately hand-locked. Power it with redstone or link a remote torch.

**Can two people share one door?**

Yes. Every player can link their own torch to the same door; all linked torches stay in sync.

**Does the pack phone home?**

No telemetry, no analytics, no network requests. All state lives in your world’s dynamic properties.

**Is it compatible with Java Edition?**

No. This is a Bedrock add-on; porting is not permitted by the licence either.

**Can I include it in my modpack or server pack?**

Not without written permission — see the [licence](license.md). Write to [yarik.internet@atomicmail.io](mailto:yarik.internet@atomicmail.io).

**Do you take commissions?**

Yes. Write to [yarik.internet@atomicmail.io](mailto:yarik.internet@atomicmail.io) with the scope and the deadline.

## Official Russian translation / Официальный русский перевод

Вопросы, которые задают на самом деле — прямые ответы.

**Нужны ли экспериментальные переключатели?**

Нет. Пак работает на стабильной 1.26.40+ со встроенным Script API 2.9.0.

**Можно ли использовать на публичном сервере?**

Да. Пак нужен серверу; игрокам самим ничего устанавливать не нужно.

**Сломает ли пак мой существующий мир?**

Ни один блок не заменяется и ни один ванильный файл не перезаписывается. Удаление пака оставляет ванильные блоки, поэтому перед удалением сделайте копию, если строили с маскировкой.

**Как привязать факел заново после поломки?**

Сломайте и поставьте: привязка хранится вместе с позицией факела. Можно также **Shift + клик** по привязанному факелу, держа свежий факел, чтобы скопировать привязку.

**Почему дверь не открывается рукой?**

Вы используете вариант `_rs`, который намеренно заперт от руки. Подайте сигнал редстоуна или привяжите беспроводной факел.

**Могут ли два человека пользоваться одной дверью?**

Да. Каждый игрок может привязать свой факел к той же двери; все привязанные факелы синхронны.

**Пак куда-нибудь отправляет данные?**

Никакой телеметрии, аналитики и сетевых запросов. Всё состояние живёт в динамических свойствах вашего мира.

**Совместимо ли с Java Edition?**

Нет. Это аддон для Bedrock; перенос также запрещён лицензией.

**Можно ли включить пак в мой модпак или серверную сборку?**

Только с письменного разрешения — см. [лицензию](license.md). Пишите на [yarik.internet@atomicmail.io](mailto:yarik.internet@atomicmail.io).

**Берёте ли вы заказы?**

Да. Пишите на [yarik.internet@atomicmail.io](mailto:yarik.internet@atomicmail.io) с объёмом работы и сроками.
