# Changelog

What changed in every release.

> **Update incoming** — A new update is coming very soon: many bug fixes, partially reworked logic, more vanilla glass blocks, and a camouflage registry grown well beyond 290+. This page covers the current release, v2.1.5.

| Version | Highlights |
| --- | --- |
| **v2.1.5** | Studio release: the project now ships under the Onyx Meridian studio licence v3.0. The previous project licence is kept alive and migrated, not replaced silently. |
| **v2.1.4** | Doors no longer drop in Creative; the torch-binding message is no longer a raw white key; one door = one drop; a half-destroyed door stays usable; orphaned upper halves are cleaned up; link copy and link removal gestures; coloured hover subtitles in both languages. |
| **v2.1.3** | Trapdoor held-item offset fixed, single-drop guard, every image and GIF under 850 px. |
| **v2.1.2** | Redstone and wireless families split, locked `_rs` variants, nineteen biome grass tints. |
| **v2.1.0 – 2.1.1** | Bedrock port, 290+ camouflage skins, spy-glass modes, split-half doors, wireless binding. |

## How to read this changelog

The table lists shipped releases only. The current page covers v2.1.5. An update is announced separately on the add-on page; announced work is not a shipped feature until a release appears here.

## Current focus
